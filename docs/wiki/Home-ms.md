# Hari 66: Wiki API Kafe

Nota untuk Hari 66 kursus Udemy 100 Days of Code: membina REST API sendiri dengan Flask. Pelajaran ini menukarkan pangkalan data kafe mesra komputer riba menjadi perkhidmatan yang boleh dipanggil oleh atur cara lain. Wiki ini menerangkan setiap langkah dan apa yang kita pelajari. Repositori ini tidak mengandungi kod aplikasi; kod itu milik kursus.

## REST secara ringkas

- **REST** (REpresentational State Transfer) ialah gaya untuk mereka bentuk aplikasi rangkaian.
- **Klien dan pelayan:** seperti tetamu dan kakitangan restoran, klien meminta dan pelayan menjawab.
- **HTTP dan HTTPS:** bahasa permintaan; HTTPS menyulitkan trafik.
- **Permintaan dan respons:** klien menghantar permintaan, pelayan mengira atau menyoal pangkalan data, lalu membalas dengan satu sumber.
- **Reka bentuk API:** API ialah menu apa yang boleh diminta oleh klien; REST memberi menu itu bentuk piawai.

## Kata kerja HTTP dan CRUD

| Kata kerja | CRUD | Digunakan untuk |
| --- | --- | --- |
| GET | Baca | Dapatkan satu sumber |
| POST | Cipta | Tambah sumber baharu |
| PUT | Kemas kini | Gantikan keseluruhan sumber |
| PATCH | Kemas kini | Ubah sebahagian sumber |
| DELETE | Padam | Buang satu sumber |

**PUT atau PATCH?** Sebuah basikal tiba dengan tayar rosak. PUT ialah menghantar balik seluruh basikal untuk yang baharu; PATCH hanya menghantar tayar. PATCH lebih cekap apabila hanya satu medan berubah.
