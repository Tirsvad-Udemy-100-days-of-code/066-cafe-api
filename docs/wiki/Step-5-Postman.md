# 5. Postman

![Postman](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/066-cafe-api/raw/branch/main/docs/images/step-5.png)

*Illustration with example data, drawn for this repository from the lecture description. It is not a capture of the course project.*

## What the lecture does

- Typing parameters in the browser's address bar is slow and error-prone; Postman lets you enter key-value pairs and builds the URL.
- Create a collection called Cafe & Wifi and save the existing routes in it.
- Request a random cafe through Postman to check the saved request.

## What we gained

- A proper tool for testing every HTTP verb.
- Saved, named requests are the raw material for the API documentation later.
