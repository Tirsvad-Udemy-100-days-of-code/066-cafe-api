# 1. The starting project

![The starting project](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/066-cafe-api/raw/branch/main/docs/images/step-1.png)

*Illustration with example data, drawn for this repository from the lecture description. It is not a capture of the course project.*

## What the lecture does

- Download the starting files, open them in PyCharm and let it create a virtual environment and install `requirements.txt`.
- Look around: `main.py`, and the SQLite database `cafes.db` in the `instance` folder, filled with cafes around London.
- Open the database in a viewer to learn the fields: name, map link, image link, location, seats, toilet, wifi, sockets, calls and coffee price.

## What we gained

- A repeatable setup: one virtual environment per project keeps packages isolated.
- Know the data before designing the API: the fields decide what the routes can offer.
